# Percepto

> Percepto is an Israeli-founded industrial autonomy company (founded 2014; Modi'in, Israel and
> the United States) that builds drone-in-a-box hardware — the Percepto Air Max and Air Mobile
> drones and the Percepto Base docking station — and Percepto AIM (Autonomous Inspection and
> Monitoring), the software that plans and launches autonomous missions, ingests visual, thermal,
> optical-gas-imaging and 3D data from Percepto drones as well as third-party DJI drones and fixed
> cameras, and applies AI analytics for inspection, monitoring, emergency response and security at
> oil and gas, mining, electric utility, solar, port and heavy-industry sites.

## API surface

Percepto publishes NO public API. There is no developer portal, no public API reference, no
OpenAPI/AsyncAPI/GraphQL/gRPC/WSDL document, no SDK and no MCP server on any Percepto host.

The Percepto AIM console at https://drones.percepto.co/ is a Django/Django-REST-Framework
application that serves an HTTP API under /api/. Both machine-readable entry points exist but are
customer-only: as of 2026-08-26, GET https://drones.percepto.co/api/schema/ and GET
https://drones.percepto.co/api/docs/ each return HTTP 302 to /loginview/?next=..., while sibling
paths (/api/, /api/v1/, /swagger.json, /redoc/, /graphql, /openapi.yaml) return the application's
404 page. An agent cannot reach this API without Percepto customer credentials.

- [Percepto AIM console (login)](https://drones.percepto.co/loginview/): the only reachable entry
  point to the AIM API.

## Security and compliance

- [Data security statement](https://percepto.co/your-drone-inspection-data-is-secure/): Percepto
  states it holds ISO 27001 certification and passed a SOC 2 Type II audit (Ernst & Young),
  published 2023-07-31.
- No /.well-known/security.txt (HTTP 404 on percepto.co and drones.percepto.co), no published
  vulnerability disclosure policy, no bug bounty and no trust center were found.
- Probed 2026-08-26: TLS 1.3 and HSTS on both hosts; SPF and DMARC (policy quarantine) on
  percepto.co; CAA records present; no DNSSEC.
